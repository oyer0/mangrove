Hardware ID databases
=====================

pci.ids is the PCI ID database maintained by the PCI ID Project at
https://pci-ids.ucw.cz/ and mirrored by pciutils/pciids.  This checkout is
the 2026.09.02 snapshot and is distributable under GPL-2-or-later or the
3-clause BSD License, as stated in the file header.

usb.ids is the USB ID Repository database maintained by Stephen J. Gowdy.
This checkout is the 2026.06.26 snapshot from usbids/usbids, corresponding to
the linux-usb.org repository.  It is distributable under GPL-2-or-later or
the 3-clause BSD License, as stated by the upstream repository.

The files are presentation data parsed by lspci and lsusb.  They are not
part of the kernel and are refreshed as part of source/image updates.
